# ExchangeDiary 改善ウォークスルー

## 実装した変更

### 1. プロフィール交換の修正（QR → テキストコピー＆共有）
- **問題**: QRコードの読み取り手段がなく、交換機能が実質的に使えなかった
- **修正**: QRコード方式を廃止し、テキストベースのコピー＆共有方式に変更
  - `📋 コピー` ボタン: `navigator.clipboard` でプロフィールJSONをクリップボードにコピー
  - `📤 共有` ボタン: Web Share API 対応端末ではネイティブ共有、非対応ではコピーにフォールバック
  - QRCodeライブラリの読み込みを削除（軽量化）

### 2. 筆跡設定の診断＆作成フロー統合
- **問題**: 「文字を登録して個性を出す」ボタンが独立モーダルで、使い勝手が悪かった
- **修正**: 「診断＆作成！」ボタン押下後に、インラインで筆跡診断の質問が表示される一連のフローに統合
  - フォーム入力 → 質問3問回答 → 計算アニメーション → フォント名＆プレビュー表示 → 「この文字でプロフィール完成！」で確定
  - プロフィールデータとフォント選択が同時に完了する

### 3. 日記を書く・送る
1. **Diary タブ**の「次の日へ」または下部の「＞」ボタンで空白のページを開きます。
2. 日記を書き、「保存」ボタンを押します。
3. 保存完了後、自動的に**「日記データ送信画面」**が開きます。
4. 「コピーする」ボタンを押して、データをクリップボードにコピーします。
5. LINEやメールで友達にそのデータを送ります。

### 4. 友達の日記を受け取る
1. **Diary タブ**の上部にある「📥 受け取る」ボタンを押します。
2. 友達から送られてきたテキストデータを貼り付けます。
3. 「日記帳に綴じる」ボタンを押すと、自分の日記帳に友達の日記が追加されます！

### 5. 設定画面の追加
- **問題**: プロフィール作成後に情報を編集する手段がなかった
- **修正**: My Page ヘッダーに「⚙ 設定」ボタンを追加
  - 名前、MBTI、血液型、星座、マイブーム、役割、気分、ひとこと、筆跡を一覧で編集可能
  - MBTI を変更すると対応する深海生物も自動更新
  - 「筆跡を再診断する」ボタンから筆跡診断モーダルに遷移可能

### 6. データの引継ぎ（機種変更）
1. **My Page**の「⚙ 設定」→「💾 データの引継ぎ」を開きます。
2. **「① データを保存する」**の「コピーする」ボタンを押し、コードを保存します（メールなどで新端末に送る）。
3. 新しい端末でアプリを開き、同様に「データの引継ぎ」画面を開きます。
4. **「② データを復元する」**の入力欄にコードを貼り付け、「データを復元する」ボタンを押します。
   ※復元すると、その端末の既存データは上書きされるので注意してください。
