# Antigravity 開発引継ぎガイド

このフォルダには「深海交換日記」のソースコードと、これまでの開発履歴（ドキュメント）が含まれています。
別の PC の Antigravity で開発を再開するには、以下の手順を行ってください。

## 1. 準備
1. この ZIP ファイルを解凍します。
2. フォルダ `ExchangeDiary` が展開されます。

## 2. Antigravity で開く
1. 新しい PC で Antigravity を起動します。
2. `ExchangeDiary` フォルダをワークスペースとして開くか、ドラッグ＆ドロップします。

## 3. コンテキストの読み込み
Antigravity はフォルダ内のファイルを認識しますが、これまでの経緯を正確に伝えるために、以下のファイルを Antigravity に「読んで」もらうか、会話の最初に伝えるとスムーズです。

- `docs/task_exchange_diary.md`: 実装タスクの完了状況
- `docs/walkthrough_exchange_diary.md`: 機能の仕様と使い方の解説

## 4. 開発の再開
これで、前の PC と同じ状態で開発を続けることができます！
「日記の受け取り機能のバグを直して」や「新しいアイテムを追加して」など、続きから指示を出してください。
